# CompendiumNG

A lightweight, modern Node.js web application for Issue-Based Information System (IBIS) dialogue mapping, reimagined and modernized from the legacy Compendium tool.

---

## Why This Exists
The original [Compendium](https://github.com/CompendiumNG/CompendiumNG) desktop application developed by The Open University’s Knowledge Media Institute (KMi) served as a foundational tool for visual dialogue mapping and tackling wicked problems. However, the original codebase relied on legacy Java desktop runtimes and embedded database configurations that are difficult to deploy and run on modern systems.

This project reconstructs and modernizes the application into a standalone Node.js web application—enabling browser-based IBIS deliberation maps, modern persistence, and friction-free setup across platforms.

---

## Features
- **Browser-Native IBIS Mapping:** Direct visual modeling of Issues/Questions, Ideas/Positions, Arguments (Pros/Cons), and Reference nodes.
- **Modern Web Stack:** Lightweight Node.js backend with an interactive canvas frontend.
- **Portability:** Fast local-first startup without legacy Java dependencies or desktop installers.
